# 日本で震度1以上を観測した地震の回数（1990〜2026年）

気象庁の震度データベースをもとに、日本で震度1以上を観測した地震の年ごとの回数（最大震度別）と、最大震度6弱以上の地震の一覧・震央の地図を示すページです。

- 年ごとの回数の棒グラフ（震度7の年に印、1997年11月の震度計追加の時期に破線）
- 年別・最大震度別の回数と、大きな地震（最大震度6弱以上）の一覧表
- 震央の地図（最大震度・年代・深さで色分け、年ごとの再生とくり返し、年の選択、拡大・縮小）

## データ

| ファイル | 内容 |
|---|---|
| `data/yearly.csv` | 年別・最大震度別の回数（震度データベース「震度別地震回数表」年別回数）。1996年9月以前の旧階級の震度5・6は、データベースの数え方どおり5弱・6弱の列に入る |
| `data/big.csv` | 最大震度6弱以上（旧階級の震度6を含む）の地震73件。発生日時・震央地名・緯度・経度・深さ・マグニチュード・最大震度・気象庁による名称 |
| `data/japan_land.json` | Natural Earth 1:50m の陸地から日本周辺を切り出し、座標を小数点以下2桁に丸めたもの |

- 取得日：2026年11月10日。期間：1990年1月1日〜2026年11月8日（データベース収録の最終日）。2026年は途中までの数です。
- 震度データベースの値は再調査で修正されることがあり、毎年1月の気象庁の報道発表の数と違う年があります。
